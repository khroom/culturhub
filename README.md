# Культурный кластер

Прототип площадки культурных встреч Финансового университета. Участник видит, куда уже идёт и куда можно пойти. Организатор ведёт свои мероприятия по этапам: хотим провести, ждём разрешения, точно будет, уже прошло или отменено.

## Как открыть

Нужен Node.js 22: база открывается встроенным модулем SQLite этой версии. Отдельный сервер базы и доступ в облако не нужны.

```bash
npm install
npm run dev
```

Приложение поднимается на порту 3847. При первом запуске пустая база SQLite в `data/cluster.sqlite` заполняется демо из `data/*.json`. Повторный запуск строки не дублирует.

На экране входа общий пароль `demo`. Логины: `maria`, `ilya`, `kira`, `arina`. Ссылка «Регистрация» видна и запись не создаёт.

## Проверки

```bash
npm test
```
